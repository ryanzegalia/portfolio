Personal production environment

Three machines in my house running real services my family uses every day. They page me when something breaks. They're on a private network, so I've shown screenshots instead of links.

Self-hosted AI

One GPU, more programs than it can serve, and a scheduler deciding who waits

Everything AI in my house, dictation cleanup, file triage, meeting summaries, job scoring, wants the same GPU. I built the scheduler that decides who waits, and a cost board that rebuilds each program's spend from its raw request logs. An agent watches the machines and investigates failures itself; paid models are the fallback, not the default.

priority scheduler · per-program spend ledger · paid models only as a fallback

Operations

14 services, one screen

I was checking ten different tabs to find out what broke. Now every service reports to one page: up or down, host vitals, what the GPU is doing, what it costs, whether the backups ran. Vanilla JavaScript and Web Components, no framework. It's the first thing I open when something's wrong.

vanilla JS · Web Components · Chart.js

Computational design

I can't do CAD, so I built a pipeline where agents do it

I can find a mesh close to what I need; I can't redraw it. So agents do the rebuild: drop in a downloaded mesh and it comes back as a real solid, holes that drill, faces that offset, ready to resize or graft a bracket onto, live in the browser. Every rebuild checks itself against the original. On my test parts it matches 99.6% of the shape, where CAD-Recode, a published research method, reaches 84.8%.

mesh in, STEP/3MF out · agents drive the rebuild · live viewer

Data pipeline

A scoring pipeline over ~102K scraped job listings

Job boards bury the listings that matter under thousands that don't. Six scrapers feed one archive, and a scoring pass reads every description and ranks it against what I do.

full-text search over every description · keyboard-first triage
