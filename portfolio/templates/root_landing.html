Personal production environment

Three machines in my house running real services my family uses every day. They page me when something breaks. They're on a private network, so I've shown screenshots instead of links.

Self-hosted AI

A scheduler and cost ledger for the one GPU my whole home lab shares

All of the AI in my home lab runs through the one GPU on my workstation, and so many different things want it at the same time that I built a scheduler to manage who gets it. A cost dashboard rebuilds what each program spent from the raw request logs. There's also an agent that watches the machines and investigates problems on its own. It uses local models first and only calls a paid model when it gets stuck.

priority scheduler · per-program spend ledger · paid models only as a fallback

Operations

14 services, one screen

Every service in my home lab reports its status to one page I built: whether it's up, how the host machines are doing, what the GPU is working on, and whether the backups ran. I wrote it in plain JavaScript with Web Components because a dashboard this size doesn't need a framework. When something breaks, this is the first place I look.

vanilla JS · Web Components · Chart.js

Computational design

An agent pipeline that rebuilds 3D meshes into editable CAD solids

I can't draw CAD from scratch, but I can usually find a downloaded mesh close to what I need. So I built a pipeline where AI agents rebuild that mesh into a real editable solid, and I make my changes from there: resize it, drill holes, add a bracket. It runs live in the browser, and every rebuild gets checked against the original shape. On my test parts it matches 99.6%, where a published research method reaches 84.8%.

mesh in, STEP/3MF out · agents drive the rebuild · live viewer

Data pipeline

A scoring pipeline over ~102K scraped job listings

Six scrapers pull job listings into one archive, and a scoring pass reads every description and ranks it against the work I actually do, so I only spend time on the ones that score high.

full-text search over every description · keyboard-first triage
