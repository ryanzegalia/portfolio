Personal production environment

Real systems on three hosts in my house, monitored, alerted, and used daily by my family. They live on a private network, so the receipts are screenshots rather than links.

Self-hosted AI

A self-hosted AI stack: local models, one GPU, and an agent watching the whole thing

Every AI workload in the house runs on local models: 13 callers behind a priority scheduler that leases out one GPU. A cost dashboard rebuilds each caller's spend from raw request logs. An investigator agent watches the environment, escalates to a paid model only when it's stuck, and once dug 360 zombie processes out of a sick host in 15 tool calls without spending a cent.

priority scheduler + GPU lease · spend ledger from raw logs · local first, paid when beaten

Operations

14 services, one screen

A single-page operator console for the home fleet: service health, host vitals, GPU state, spend, backups, whatever each service will admit to. Vanilla JavaScript and Web Components, no framework, because a homelab dashboard doesn't need one. I've run a live interview demo from it.

vanilla JS · Web Components · Chart.js and nothing heavier

Computational design

A CAD pipeline that rebuilds a scanned or exported mesh into an editable solid

Drop in a mesh from a scan, a marketplace download, or another tool's export, and an agent pipeline reconstructs it as a parametric solid with holes that actually drill and faces that actually offset, live in the browser. On benchmark parts it rebuilds at 0.996 voxel overlap where CAD-Recode, a published neural method, topped out at 0.848. The server-rack case and device trays in the shots were designed end-to-end in it.

mesh in, STEP/3MF out · voxel-IoU self-check on every rebuild · live viewer

Data pipeline

The job-search radar: ~102K postings scraped and scored

A handful of scrapers feed one archive. A scoring pass reads every description against what I actually do and ranks the day's catch. The same shape as a vendor data feed: ingest, normalize, score, rank.

six sources · full-text search over every description · keyboard-first triage
